# 拼音逻辑迷宫 · PINYIN / LOGIC MAZE

适合小学拼音学习阶段的纯前端 H5 逻辑解谜应用。

**网页地址**（须先在仓库 GitHub Pages 设置中启用）：https://zbc1206.github.io/pinyin-castle/

## 学习结构

- **声母城堡**：镜像字形、双唇送气、舌位分类、平翘舌对照、综合排除。
- **韵母城堡**：单韵母、复韵母、前后鼻音、四声、ü 的省点规则。
- **整体认读城堡**：七个基础音节、yi/wu/yu、六个 y 开头的音节、真假分类、16 音节总复核。
- **总控密室**：综合知识推理；三个城堡各完成至少一关解锁。

共 **16 个关卡、51 道原创谜题**。四种互动：多条件排除、集合筛选、顺序修复、关系配对。每道题提供线索、可选提示和解题后的规则说明。猜错可以重试，使用提示会影响得分。

## 学习辅助

- 拼写实验台：切换 j/q/x/n/l 和 ü/üe，对照规范拼写。
- 规则档案：通关后获得本关知识卡。
- 学习记录：关卡、最高分、星级和需要复练的错题保存在当前浏览器。
- 顺序闯关 / 自由探索切换。
- 示例字朗读来自设备中文语音合成，并非专业声母、韵母录音。

## 部署

在仓库 **Settings → Pages** 选择 **Deploy from a branch**，选择 **main** 和 **/ (root)**，保存即可。

所有文件均在仓库根目录：
- index.html：页面入口
- styles.css：界面及响应式样式
- puzzles.js：关卡题库、线索和解析
- app.js：交互引擎、评分、规则档案、实验台

无后端、CDN 或框架依赖。可通过 GitHub Pages 静态托管。

## 教学边界

这是一款拼音规则和逻辑推理辅助工具，不能替代真人规范发音、语流拼读和听辨训练。设计采用小学常用 23 声母、24 韵母、16 整体认读音节体系。
