# 未来文字探索基地 V4

基于小学低年级拼音与识字学习目标设计的静态 H5：以科技探索世界为视觉，围绕 **韵母 → 完整拼读 → 汉字 → 词语 → 句子 → 短文理解** 建立一条进阶路线。

## 在线地址

https://zbc1206.github.io/pinyin-castle/

如果显示 404，请在仓库 Settings → Pages 中配置 Deploy from a branch / main / (root)。

## 三个基地

1. **科技未来韵母基地**：8 节课。从 a o e、i u ü 开始，按顺序学到 24 个韵母；含四类韵母的总复习。
2. **星际拼读实验基地**：7 节课。声母、两拼、三拼、四声、ü 两点省略、16 个整体认读音节、标调规则。
3. **汉字认知探索基地**：7 节课。字音字形字义、自然字、组词、汉字构字规律、减少拼音提示、句子理解、观察短文。

总计 22 节课程、88 道课堂交互练习。题型包括单项判断、多项分类、顺序组合，提供正确答案解释、错误重试、课程星级和错题记录。

## 运动实验场

- **足球拼读赛**：认读完整带调音节，答对射门。
- **篮球声调赛**：辨认四声，答对投篮。
- **保龄识字赛**：汉字认读、词语、字形、句意，答对击倒球瓶。

各 6 题，共 18 道运动挑战题。运动动画不是随机胜负，受学习答案控制。

## 教学注意事项

语音按钮使用设备中文语音合成朗读示例汉字和词语；**不是声母或韵母的专业标准发音录音**。训练重点是识别、拼写、拼读规则与认字，不能替代老师示范、真人朗读、听辨与真实文本阅读。学习记录仅保存在当前浏览器 localStorage，清理浏览器数据后可能丢失。
